실제 저장 데이터의 정수 인코딩 예시

원문 문서: kowiki/282586 / 고야마못
사전: training-corpora/wiki-k35328/vocabulary.json
배열: training-corpora/wiki-k35328/train.ids.npy

1. OOV 필터를 통과한 실제 첫 문장의 형태소/품사 토큰
이름/NNG 은/JX <sp>/WS 못/MAG 이/VCP 지만/EC <sp>/WS 커다랗/VA-I ᆫ/ETM <sp>/WS 석호/NNG 이/VCP 다/EF ./SF <sp>/WS

2. 같은 사전에 따른 정수 ID (0부터 시작)
[153, 21, 4, 330, 16, 78, 4, 4100, 12, 4, 13645, 16, 8, 5, 4]

3. vocabulary[ID]로 역변환한 토큰
이름/NNG 은/JX <sp>/WS 못/MAG 이/VCP 지만/EC <sp>/WS 커다랗/VA-I ᆫ/ETM <sp>/WS 석호/NNG 이/VCP 다/EF ./SF <sp>/WS

검증: 위 ID는 실제 train.ids.npy의 8번 인덱스부터 저장된 값과 같습니다.
이 문단 전체의 ID도 원문 연결 기록·보존된 모든 토큰·BOS/EOS를 이용해 재구성하여 일치 확인했습니다.
문단 맨 앞 8개 ID는 문맥용 <bos>=2, 문단 끝 ID는 <eos>=3입니다.
형태소/품사 토큰 ↔ ID 변환은 정확히 일치합니다. 원문 문자 전체의 무손실 복원을 뜻하지는 않습니다.

4. NumPy로 읽기 (korean-wiki 작업 폴더 기준)
import numpy as np
ids = np.load("training-corpora/wiki-k35328/train.ids.npy", mmap_mode="r", allow_pickle=False)

.npy는 배열의 자료형·크기를 함께 저장합니다. uint16 ID 하나는 2바이트입니다.
토큰 문자열을 매번 읽고 정수로 변환하는 일을 미리 처리한 형태입니다.
