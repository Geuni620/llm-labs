### 열·전원 점검과 중단 조건

- [x] macOS `ProcessInfo.thermalState`를 5초마다 읽으며, 읽기 실패·`serious`/`critical`·deadline·감시 정지 상황을 모의 테스트 33개로 검증했다. `serious`/monitor 오류에서는 새 갱신을 중단하고 가능하면 저장 후 종료한다. 30초 내 종료 확인이 없으면 강제 종료한다. `critical`에서는 연산 중단을 우선하며 5초 내 확인이 없으면 종료한다. 마지막 완전한 감시 갱신이 20초 없으면 오류로 중단한다. 자동 재시작하지 않는다. Apple의 화재 판정 온도가 아니다.
- [x] 열 상태 조회는 CPU 온도계나 화재 감지기가 아님을 로그·metadata에 명시했다. 현재 `nominal`만으로 장시간 안전이나 배터리·충전기의 정상 작동을 보증하지 않는다. 모니터링 오류를 정상 상태로 간주하지 않는다.
- [x] 사용자 확인: 책상 위에 놓았고 외관 이상 없음. 2026-10-22 읽기 전용 점검에서는 macOS 배터리 상태 `Check Battery`, 최대 용량 79%, 사이클 409회가 보고됐다. 이 수치만으로 발화 위험이나 즉시 사용 불가를 뜻하지는 않는다.
- [x] 사용자 확인: 통풍되는 단단한 책상 위. macOS의 열·전원 보호는 해제하지 않았다. 외관을 에이전트가 직접 진단한 것은 아니다.
