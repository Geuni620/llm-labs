# Step 2. 샘플 추출

parquet 원본 데이터를 사람이 읽을 수 있는 형태로 뽑아서 수동 검토한다.

## 왜 필요한가

parquet 는 바이너리 포맷이라 내용을 바로 볼 수 없다.
클리닝 규칙을 설계하기 전에 원본 데이터가 어떻게 생겼는지 눈으로 확인해야 한다.

## 흐름

첫 번째 파일에서 10행, 두 번째 파일에서 5행 — 합계 15행을 추출한다.

```python
FILES = [
    ("parquet/data/kowiki/000_00000.parquet", 10),
    ("parquet/data/kowiki/000_00001.parquet", 5),
]
```

각 행은 14개 컬럼을 갖는다. 짧은 메타 필드는 `key: value` 로, 긴 텍스트 필드는
`--- text ---` 같은 섹션 구분자로 나누어 출력한다.

```
================================================================================
=== Row 1/15   source: 000_00000.parquet   local index: 0
================================================================================

id             : kowiki/282586
title          : 고야마못
url            : https://ko.wikipedia.org/wiki/고야마못
page_id        : 282586
date_modified  : 2024-10-09T23:30:35Z
wikidata_id    : Q3214989
bytes_html     : 44879

--- text ---
# 고야마못
고야마못(일본어: 湖山池 고야마이케[*])은 돗토리현 돗토리시 남서부에 위치한
기수호이다. 이름은 못이지만 커다란 석호다. 고대에는 만(湾)이었으나, 사구의
발달과 퇴적으로 바다에서 분리되어 석호가 되었다. ...

--- wikitext ---
{{위키데이터 속성 추적}}
{{호수 정보
|이름 = 고야마못
|호수그림 = 湖山池.jpg
|면적 = 6.96
...
```

`text`는 이미 HTML/마크업이 제거된 본문, `wikitext`는 원본 마크업이다.
Step 3에서는 `text` 컬럼만 사용한다.

## 입출력

```
입력: parquet/data/kowiki/*.parquet (앞 15행)
출력: sample_15rows.txt
```
