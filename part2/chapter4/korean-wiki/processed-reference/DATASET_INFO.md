# 한국어 위키백과 데이터셋

Part 2 Chapter 4의 다른 데이터와 구분하는 한국어 위키백과 학습 데이터입니다.
배치 경로는 `part2/chapter4/datasets/korean_wiki/`입니다.
이 폴더를 추가하는 것만으로 기존 학습 코드의 기본 입력은 바뀌지 않습니다.

출처는 `HuggingFaceFW/finewiki`의 한국어 파일 경로 `data/kowiki/`입니다. 제공된
`ko_wiki_cleaning.7z`의 파일을 모두 압축 해제한 뒤, 원래 포함된 문서와
전처리 스크립트 및 데이터 파일을 함께 보존합니다.

## 원본 시점 확인 — 2026-10-17

패키지에 들어 있는 다운로드 캐시가 기록한 Hugging Face revision은
`8bd13e72e6a002407649b3e898535f42ceb1aeb9`입니다.
이 고정 revision의 공식 데이터셋 카드에는 **2025년 8월 위키백과 HTML

- Hugging Face 저장소 생성: 2025-10-13.
- 해당 revision 날짜: 2025-10-22.
- 패키지 안 다운로드 캐시 기록: 2026-04-08 13:45:38 KST.
  제공자의 다운로드 기록이며, 이 컴퓨터에서 직접 내려받은 시각을 뜻하지 않습니다.
- 캐시에 기록된 Parquet 두 개의 SHA-256 식별자는 원격 고정 revision과 모두 일치합니다.
- 원본 Parquet은 제공 압축본에 없으므로, 전처리 결과를 원본부터 재생성해
  일치 여부를 검증한 것은 아닙니다.

공식 설명: <https://huggingface.co/datasets/HuggingFaceFW/finewiki/blob/8bd13e72e6a002407649b3e898535f42ceb1aeb9/README.md>

파일 식별자와 확인 기록은 [PROVENANCE.json](PROVENANCE.json)에 있습니다.
제공된 `step1_download.py`는 `revision`을 지정하지 않으므로 재실행하면
당시의 기본 브랜치에서 다운로드합니다. 특정 시점의 데이터를 재현하려면
revision을 명시해야 합니다.

## 포함 데이터

- `paragraphs_raw/`: 구조 행 등을 제거한 비교용 문단. 가공 전 원본은 아닙니다.
- `paragraphs/`: 정제 문단 2,618,729개.
- `sentences/`: 문장 분할 결과 7,099,328개.
- `sentences_dedup/`: 중복 제거 문장 6,677,632개. 문장을 직접 읽고 분석할 때 사용합니다.
- `tokens/`: Kiwi 형태소·품사 토큰 292,630,218개.
- `vocab_*.txt`: 어휘 사전. 각 행은 `토큰\t빈도`이며, 0부터 세는 행 번호가 토큰 ID입니다.
- `token_ids_{16384,32768,49152,65536}/`: 어휘 크기별 32개 샤드의 최종 학습 입력. 각 `.npy`는 1차원 `uint16` 배열입니다.
- `ngram_*.pkl`: 제공 압축 파일에 포함된 N-gram 집계 파일.
- `step*.py`, `step*.md`, `README.md`: 원본 제공자의 전처리 코드와 설명.

최종 ID 배열의 토큰 수는 어휘 크기 순서대로 73,437,479 / 124,445,087 /
153,222,754 / 171,806,989개입니다. 어휘 사전에 없는 토큰이 포함된 문장은
문장 전체를 제거하므로, 어휘 크기에 따라 유지되는 학습 데이터가 다릅니다.

## 제공 압축본에서 제외된 항목

원본 Parquet, `tokens_filtered_*`의 텍스트, `tokens_verify_mismatches.txt`는
제공 압축본에 포함되지 않았습니다. 일부 폴더에 `README.txt`만 있는 것은
정상이며, 필요한 경우 원본 `README.md`의 절차로 재생성할 수 있습니다.
최종 `token_ids_*/*.npy`와 `vocab_*.txt`는 포함되어 있습니다.

## 파일 형식

- 원본 배포 형식: Parquet 두 개, `text`, `title`, `url`, `date_modified` 등을
  포함한 14개 컬럼. 이 패키지에서는 안내문과 다운로드 메타데이터만 남아 있습니다.
- `paragraphs*/*.txt`, `sentences*/*.txt`: UTF-8 텍스트. 문단 파일은 한 줄이
  한 문단이고, 문장 파일은 한 줄이 한 문장입니다. 빈 줄은 문단 경계입니다.
- `tokens/*.txt`: UTF-8 형태소/품사 토큰열. 예: `이름/NNG 은/JX <sp>/WS ...`.
- `vocab_*.txt`: 탭으로 구분한 `토큰`과 `빈도` 두 필드. 헤더 행이 없습니다.
- `token_ids_*/*.npy`: NumPy 1차원 little-endian `uint16` 배열.
  예: `token_ids_32768/part_00.npy`의 shape은 `(4210724,)`입니다.
- `ngram_*.pkl`: Python pickle 직렬화 형식의 N-gram 집계 파일 두 개.
- `.py`, `.md`, `.png`: 전처리 코드, 설명 문서, 어휘 통계 그림입니다.

위키 데이터의 특수 토큰은 `<pad>`=0, `<unk>`=1, `<bos>`=2, `<eos>`=3입니다.
Chapter 4 기본 6문장 예제의 ID 배치와 다르므로 기존 코드가 자동으로
위키 데이터를 읽는다고 가정하면 안 됩니다.

## 중복 검사

[audit_duplicates.py](audit_duplicates.py)는 원본을 수정하지 않고 32개 샤드
전체를 검사합니다. 결과는 [audit/duplicates.json](audit/duplicates.json)에 저장합니다.
원본과 중복 제거 후의 NFKC·공백 정규화 문장, 형태소 토큰열,
어휘 크기별 최종 ID 문단 시퀀스를 구분해서 검사합니다.
공백·문장부호·대소문자나 숫자만 다른 문장은 유사 후보로 별도 집계하며,
그 수치를 동일한 데이터의 중복으로 확정하지 않습니다.

### 전수 검사 결과 — 2026-10-17

아래 중복 수는 각 동일 그룹의 첫 항목을 제외한 **추가 등장 수**입니다.

- `sentences/`: 7,099,328개 중 추가 중복 421,696개(194,939개 그룹).
- `sentences_dedup/`: 6,677,632개 중 정규화 문장 중복 **0개**.
  원본의 고유 문장 집합과 출력의 집합도 완전히 일치합니다.
- `tokens/`: 정확히 같은 토큰 줄의 추가 중복 **472개**(470개 그룹).
  문장 끝 공백 토큰의 차이까지 무시하면 **682개**(680개 그룹)입니다.
  이 682개에는 앞의 472개가 포함됩니다.
- 최종 ID 문단 시퀀스 추가 중복: 어휘 16,384에서 **96개**,
  32,768에서 **101개**, 49,152에서 **94개**, 65,536에서 **93개**.
  각 어휘 버전 안에서 문단 전체 ID 시퀀스가 같은 경우만 센 수치입니다.
- 공백·문장부호·영문 대소문자를 무시하면 같은 형태가 되는 후보:
  추가 항목 7,617개. 숫자열을 치환하면 같은 틀이 되는 후보: 76,127개.
  두 수치는 확정 중복 수가 아니며 서로 더할 수 없습니다.

실제 예로 `2020년에 입단하였다.`와 `2020년에 입단했다.`는 원문 문자열은
다르지만 형태소 토큰열은 완전히 같습니다. 문장 중복 제거 후의 형태소
변환에서 같은 학습 입력이 다시 생길 수 있습니다.

이 검사는 원문·토큰·ID 배열을 수정하지 않습니다. 원본 위키 문서의
ID·URL·문서 경계는 해당 텍스트 산출물에서 보존되지 않았고, 원본 Parquet도
패키지에 없어 문서 전체 단위의 중복은 이 검사로 확정하지 않았습니다.
의미가 같은 모든 문장을 판별하는 의미 기반 중복 검사도 아닙니다.
