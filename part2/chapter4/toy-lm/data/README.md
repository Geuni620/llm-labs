# 데이터 — 문장 6개에서 학습 쌍 24개로

이번 실습의 데이터는 다음 여섯 문장입니다. [data.ts](data.ts)의 `SENTENCES`가 모델이 실제로 사용하는 원본입니다.

```text
철수는 사과를 좋아해
철수는 딸기를 좋아해
영희는 사과를 좋아해
영희는 딸기를 좋아해
영희는 바나나를 좋아해
짱구는 바나나를 싫어해
```

주어는 철수는·영희는·짱구는, 대상은 사과를·딸기를·바나나를, 행동은 좋아해·싫어해입니다. 일반 단어는 총 8개입니다. 가능한 모든 조합을 학습한 것이 아니라 위의 6개만 사용했습니다.

## 어휘와 문장 경계

문자열을 공백으로 나눈 단어가 일반 토큰입니다. 모델에서는 각 토큰을 정수 ID로 바꿉니다.

- `<pad>`: 문장 앞의 부족한 문맥을 채웁니다.
- `<bos>`: 문장 시작을 표시합니다.
- `<eos>`: 문장 끝을 표시합니다.

일반 토큰 8개와 특수 토큰 3개를 합쳐 어휘 크기 V는 **11**입니다. 단어 ID는 단어를 가리키는 번호이며, 임베딩 좌표나 확률이 아닙니다.

## 한 문장은 네 개의 다음 토큰 예측 문제다

트라이그램은 앞의 두 토큰을 입력받아 다음 토큰 하나를 예측합니다.

```text
<pad> <bos> 철수는 사과를 좋아해 <eos>

(<pad>, <bos>)    → 철수는
(<bos>, 철수는)   → 사과를
(철수는, 사과를)  → 좋아해
(사과를, 좋아해)  → <eos>
```

문장마다 4쌍이 나오므로 전체 학습 쌍은 **6 × 4 = 24개**입니다. 문장 경계를 넘어 다른 문장을 이어 붙이지 않습니다.

## 실행과 다음 단계

실습 루트(`toy-lm/`)에서 `npm run data`를 실행합니다. 관측하지 않은 조합을 살펴보기 위한 `철수는 바나나를 좋아해`는 학습에 추가하지 않았습니다. 원본 여섯 문장은 트라이그램과 NPLM에 동일하게 제공합니다.
