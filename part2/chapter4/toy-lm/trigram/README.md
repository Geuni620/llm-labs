# 트라이그램 — 횟수로 다음 토큰의 확률 계산하기

N=3인 트라이그램은 **앞의 두 토큰으로 다음 토큰 하나를 예측**합니다. [trigram.ts](trigram.ts)는 문맥별 등장 횟수를 저장하고 MLE 또는 add-k로 확률을 구합니다.

## MLE의 분모는 같은 문맥 뒤의 전체 횟수다

학습 문맥 `(<bos>, 철수는)` 뒤에는 사과를·딸기를 각각 한 번 관측했습니다.

```text
P(사과를 | <bos>, 철수는) = 1 / 2 = 50%
P(딸기를 | <bos>, 철수는) = 1 / 2 = 50%
P(바나나를 | <bos>, 철수는) = 0 / 2 = 0%
```

분모는 문장 수 6이나 전체 학습 쌍 수 24가 아니라, 이 문맥의 관측 횟수인 2입니다.

## add-k의 k는 가상의 관측 횟수다

```text
P(후보 | 문맥) = (후보의 관측 횟수 + k)
               / (문맥의 전체 관측 횟수 + k × V)
```

V는 특수 토큰을 포함한 어휘 크기 11입니다. 모든 후보에 같은 k를 더하고 분모도 늘립니다. add-k를 사용해도 트라이그램입니다. N은 문맥 길이를, k는 스무딩의 크기를 정합니다.

문맥 `(철수는, 사과를)` 뒤에는 좋아해만 1회 관측했습니다.

| k | 좋아해 | 관측하지 않은 후보 각각 | 정규화 분모 |
| --- | ---: | ---: | ---: |
| 0 | 100.00% | 0.00% | 1 |
| 0.01 | 90.99% | 0.90% | 1.11 |
| 0.5 | 23.08% | 7.69% | 6.5 |

표는 반올림한 값입니다. k=0.5이면 실제 관측 1회에 가상 횟수 5.5회가 더해집니다. k가 커질수록 균등 분포에 가까워지며, 원하는 특정 후보의 확률만 올리는 설정은 아닙니다.

처음 보는 문맥 자체에 대해서는 현재 MLE가 미정으로 표시하고, k>0인 add-k는 11개 후보를 균등하게 예측합니다. 관측한 문맥에서 특정 후보의 횟수가 0인 경우와 구분합니다.

## 실행과 검증

실습 루트(`toy-lm/`)에서 실행합니다.

```sh
npm run trigram -- --context 철수는,사과를 --k 0.01
npm run trigram -- --context 철수는,바나나를 --k 0.01
```

MLE의 학습 PPL은 약 **1.5651**, add-k(k=0.01)의 학습 PPL은 약 **1.6514**입니다. 관측된 분포에 맞추는 정도와 처음 보는 조합에 확률을 주는 효과를 구분합니다.
