# NPLM — 임베딩에서 역전파까지 직접 계산하기

[nlm.ts](nlm.ts)는 Bengio(2003)를 기반으로 한 피드포워드 신경망 언어 모델입니다. NLM은 신경망 언어 모델의 넓은 명칭이고, 이 실습에서는 NPLM을 해당 구조의 이름으로 사용했습니다. 신경망은 이보다 넓은 개념으로, 이미지나 음성 모델에도 사용됩니다.

## 입력·은닉층·출력층의 크기

대표 설정은 어휘 V=11, 임베딩 차원 D=2, 은닉 뉴런 H=8입니다.

```text
입력 두 토큰
  → 같은 임베딩 표에서 2차원 벡터를 각각 조회
  → 두 벡터를 이어 붙여 숫자 4개
  → 완전연결 은닉층 8개 + tanh
  → 완전연결 출력층 11개 점수
  → softmax로 11개 후보의 확률
```

출력 뉴런 수는 **예측할 어휘의 크기 11**로 정합니다. 같은 모델이 문장의 모든 위치에서 주어·과일·동사·문장 끝을 예측합니다.

| 학습 변수 | 크기 | D=2, H=8의 숫자 수 |
| --- | --- | ---: |
| E: 임베딩 표 | V × D | 22 |
| W1: 입력→은닉 가중치 | 2D × H | 32 |
| b1: 은닉 편향 | H | 8 |
| W2: 은닉→출력 가중치 | H × V | 88 |
| b2: 출력 편향 | V | 11 |

총 **161개** 숫자를 학습합니다. H=6이면 입력→은닉 연결 가중치는 4×6=24개입니다. 은닉 뉴런 수를 6으로 고정한 구현은 아닙니다.

## 순전파와 loss

```text
x = concat(E[앞 토큰], E[뒤 토큰])
h = tanh(x W1 + b1)
z = h W2 + b2
p = softmax(z)
loss = -ln(p[정답])
```

z는 확률이 되기 전의 점수인 logit입니다. softmax가 점수에 exp를 취하고 전체 합으로 나눕니다. 이미 확률인 60%·40%를 loss에 사용할 때는 softmax를 다시 적용하지 않습니다.

정답이 좋아해이고 그 확률이 40%인 설명용 예시라면 loss는 `-ln(0.4) ≈ 0.9163`입니다. loss는 오답의 백분율이 아니며, 정답에 높은 확률을 줄수록 0에 가까워집니다. 실제 코드는 log-sum-exp로 안정적으로 계산합니다.

## 역전파와 경사하강법

역전파는 각 변수의 기울기를 계산합니다. 출력층 → 은닉층 → 임베딩 표 순서로 연쇄법칙을 적용하며, 같은 단어가 여러 번 등장하면 해당 임베딩 행의 기울기를 누적합니다.

기울기를 전부 구한 다음 경사하강법으로 다섯 변수 그룹을 갱신합니다.

```text
새 가중치 = 기존 가중치 − 학습률 × 기울기
```

학습률은 같은 기울기에 대한 수정량을 얼마나 크게 반영할지 정하는 배율입니다. 기울기가 양수면 가중치를 줄이고, 음수면 늘립니다. 줄이려는 대상은 loss입니다.

현재는 학습 쌍 24개 전체의 평균 기울기로 한 번 갱신하는 **full-batch GD**입니다. 전체 데이터를 한 번 사용하는 것이 1에포크이고, 이 구현에서는 에포크당 갱신도 1회입니다. SGD·미니배치·Adam은 후속 범위입니다.

## 실행과 검증

실습 루트(`toy-lm/`)에서 실행합니다.

```sh
npm run trace -- --dim 2 --hidden 6
npm run compare
npm run animate
```

`trace`는 초기 모델 한 문제의 계산과 한 번 갱신을 보여줍니다. `animate`는 대표 설정 D2·H8·lr0.3·seed123의 학습 가중치를 기록해 재생합니다.

자동 미분·딥러닝 라이브러리를 사용하지 않습니다. 실제 24쌍과 D=1·2·3, H=8에서 모든 변수 성분의 기울기를 수치 미분과 대조합니다. 반복된 단어의 임베딩 누적도 포함됩니다.
