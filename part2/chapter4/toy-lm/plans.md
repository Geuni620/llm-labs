# Chapter 4 — Node.js로 트라이그램과 신경망 언어 모델 비교

상태: TypeScript 구현과 스무딩을 함께 진행하도록 합의했다. 10,000개씩 생성, 학습률 비교, 대표 퍼플렉시티 세 가지 사례를 실험에 포함한다.

진행 결과: TypeScript 구현과 타입 검사, 수치 미분 대조를 완료했다. 파일 수를 줄이기 위해 일반 테스트와 브라우저 QA 파일 8개는 제거하고, 수동 역전파를 검산하는 `scripts/gradcheck.ts`만 남겼다. 기본 설정의 36회 학습과 140,000개 생성 결과를 기록했고, 각 모델·설정의 10,000개 및 분류 합계를 확인했다. 학습 단계별로 data·trigram·nplm·generation 디렉토리를 나누었고, 상세 지표는 로컬 실험 리포트 `results/report.md`에 있다.

## 1. 목적과 범위

같은 한국어 문장 6개로 카운트 기반 트라이그램과 신경망 언어 모델을 직접 구현하고, 다음 단어의 확률을 어떻게 계산하고 학습하는지 비교한다.

- 실행 환경: Node.js 24.12 이상 + TypeScript. 신경망의 수치 연산은 배열과 반복문으로 직접 구현한다.
- 신경망은 Bengio et al. (2003)의 *A Neural Probabilistic Language Model*을 기반으로 한다.
- 순전파, loss, 역전파, 가중치 갱신을 직접 구현한다. 학습 가능한 임베딩도 함께 갱신한다.
- 임베딩 차원 `D = 1, 2, 3`을 비교한다.
- 계획과 실험 과정은 세션에서 짧은 한국어 문장과 ASCII·Mermaid 다이어그램으로 설명한다.
- 은닉 뉴런 수 `H`는 변경 가능한 설정값으로 둔다. `H = 6`은 연결 수 설명을 위한 예시이며 고정 조건이 아니다.
- ZIP은 참고 자료로 보관하며 압축을 다시 풀지 않는다. Python·C 버전은 이번 구현 범위에 포함하지 않는다.

## 2. 데이터와 토큰화

ZIP의 `minimal_example/python/data.py`에 있는 다음 6문장을 그대로 사용한다.

```text
철수는 사과를 좋아해
철수는 딸기를 좋아해
영희는 사과를 좋아해
영희는 딸기를 좋아해
영희는 바나나를 좋아해
짱구는 바나나를 싫어해
```

공백으로 구분된 어절 하나를 토큰 하나로 취급한다.

- 주체: `철수는`, `영희는`, `짱구는`
- 대상: `사과를`, `딸기를`, `바나나를`
- 행동: `좋아해`, `싫어해`

일반 어휘는 총 8개다. ZIP과 같은 문장 경계 처리를 사용하면 `<pad>`, `<bos>`, `<eos>`를 포함한 공통 어휘 크기는 `V = 11`이다. 두 모델은 같은 토큰 ID, 입력 쌍, 출력 어휘를 사용한다.

각 문장을 `<pad> <bos> 단어1 단어2 단어3 <eos>`로 감싸고, 앞의 두 토큰으로 다음 토큰을 예측한다.

```text
(<pad>, <bos>) → 철수는
(<bos>, 철수는) → 사과를
(철수는, 사과를) → 좋아해
(사과를, 좋아해) → <eos>
```

한 문장당 4쌍이므로 전체 학습 쌍은 24개다. 문장 경계를 넘어 학습 쌍을 만들지 않는다.

## 3. 트라이그램: N = 3

문맥 길이는 2이며, 예측 대상까지 포함한 N은 3이다.

```text
P(다음 단어 | 앞 단어1, 앞 단어2)
  = 세 토큰의 등장 횟수 / 앞 두 토큰의 등장 횟수
```

- 문맥별 후보, 등장 횟수, 분모, 확률을 출력한다.
- 기본 모델은 원시 카운트의 최대우도 추정(MLE)으로 시작한다.
- 본 문맥에서 등장하지 않은 후보는 확률 0이다.
- 문맥 자체가 처음 등장하면 분모가 0이므로 MLE로는 분포를 정할 수 없다고 표시한다.
- MLE 결과를 보존하고 add-k 버전을 이번에 함께 구현한다. 기본값은 `k = 0.01`이고 변경 가능하다. 미관측 문맥의 균등 분포는 이 스무딩 정책의 결과로 구분한다.
- 확률 0인 정답의 loss는 무한대다. 이를 작은 양수로 바꿔 계산한 값을 원래 MLE 결과로 보고하지 않는다.

## 4. 신경망의 순전파와 완전연결

```text
두 토큰 ID
→ 같은 임베딩 테이블에서 각 D차원 벡터 조회
→ 두 벡터를 이어 붙인 2D차원 입력
→ 완전연결 은닉층 H개 뉴런 + tanh
→ 완전연결 출력층 V개 점수(logits)
→ softmax로 다음 토큰 확률
→ 정답 토큰에 대한 cross-entropy loss
```

임베딩 벡터의 모든 성분이 모든 은닉 뉴런에 연결된다. 서로 다른 입력 위치는 서로 다른 은닉층 가중치를 사용하고, 두 위치의 단어 벡터는 같은 임베딩 테이블에서 가져온다.

- 임베딩 테이블 `E`: `V × D`
- 임베딩 입력 → 은닉층 가중치 `W1`: `2D × H`, 편향 `b1`: `H`
- 은닉층 → 출력층 가중치 `W2`: `H × V`, 편향 `b2`: `V`

`D = 2`, `H = 6`인 예에서는 입력 성분이 4개이므로 은닉층으로 이어지는 가중치는 `4 × 6 = 24`개다. 은닉층 편향 6개는 연결 가중치와 별도로 센다.

```text
x = concat(E[앞 단어1], E[앞 단어2])
h = tanh(x W1 + b1)
z = h W2 + b2
p = softmax(z)
loss = -log(p[정답])
```

논문 Section 2, 식 (1)은 임베딩 입력에서 출력층으로 이어지는 직접 연결을 선택 사항으로 두고, 해당 가중치를 0으로 둘 수 있다고 명시한다. 이번 기본 모델은 그 직접 연결을 생략한 구조를 사용한다. 정규화와 대규모 코퍼스 실험은 후속 범위로 둔다. [원문 PDF](https://www.jmlr.org/papers/volume3/bengio03a/bengio03a.pdf)

## 5. loss, 역전파, 학습

- softmax는 최대 logit을 빼서 계산하고, loss는 log-sum-exp로 안정적으로 계산한다.
- loss에서 출력층 → 은닉층 → 임베딩 테이블 순서로 미분한다.
- `E`, `W1`, `b1`, `W2`, `b2`를 모두 갱신한다.
- 같은 단어가 여러 입력에 등장하면 그 단어의 임베딩 gradient를 합산한다.
- 모든 gradient는 갱신 전의 같은 가중치로 계산한 뒤, 가중치를 한꺼번에 갱신한다.
- 학습 쌍 24개 전체의 평균 loss로 한 번씩 갱신하는 full-batch gradient descent를 사용한다.
- 학습률, 반복 횟수, 초기화 seed, `H`를 설정값으로 둔다.
- 임베딩 차원 비교에서는 `H`, 학습률, 학습량, 데이터와 평가 조건을 동일하게 유지한다.

## 6. 비교할 결과

1. **관측된 문맥의 분포**: 예를 들어 `(철수는, 사과를)` 다음 후보 확률을 비교한다.
2. **관측하지 못한 조합**: `(철수는, 바나나를)` 다음 `좋아해`, `싫어해` 등의 확률을 비교한다. 이 문장은 원래 6개에 추가하지 않는다.
3. **학습 경과**: 초기·최종 평균 loss, loss 곡선, 학습 데이터 perplexity를 기록한다. 동일한 평가 쌍과 토큰 기준에서 `perplexity = exp(평균 loss)`로 계산한다.
4. **임베딩 차원**: 1차원은 선 위의 위치, 2차원은 평면, 3차원은 공간 좌표로 일반 단어 8개의 학습 전후 변화를 확인한다.
5. **재현성**: 먼저 고정 seed로 구현을 확인하고, 결과 해석에서는 여러 seed의 편차도 확인한다.

학습 데이터의 loss는 학습 적합도를 나타낸다. 미관측 조합의 확률은 작은 데이터에서의 탐색 결과로 해석한다. 특정 문장의 높은 확률이나 차원이 커질수록 좋아지는 결과를 미리 전제하지 않는다. 동일한 문맥에 여러 정답이 있으므로 최종 평균 loss가 0이 되어야 한다는 조건도 두지 않는다.

`D`가 바뀌면 모델의 매개변수 수도 변하므로 각 실험에서 이를 함께 기록한다. 결과는 세션에서 후보별 확률표, loss 기록, 좌표표와 텍스트 다이어그램으로 함께 설명하고 JSON·CSV·리포트로 저장한다.

### 학습률과 퍼플렉시티 실험

- 기본 실험: `D = 1, 2, 3`, `H = 8`, 학습률 `0.05, 0.1, 0.3, 1.0`, 학습 2,000회.
- 각 설정을 학습 seed `123, 456, 789`로 반복한다. 총 36회 학습이다.
- 같은 D와 seed에서는 학습률을 바꾸더라도 초기 가중치를 동일하게 유지한다.
- 학습률별 최종 loss 평균·표준편차와 PPL 평균을 표로 제공한다.
- 대표 세 가지 사례는 D=2, H=8을 유지한 학습률 0.05, 0.3, 1.0이다.
- PPL은 직접 설정하거나 목표값으로 바꾸는 값이 아니다. 같은 24개 학습 쌍의 평균 loss에서 계산하고, 균등 기준 11 및 MLE 기준과 비교한다.

### 10,000개씩 문장 생성

- 원시 트라이그램, add-k 트라이그램, 각 D·학습률의 신경망으로 각각 10,000개를 생성한다.
- 신경망 생성은 각 설정의 첫 학습 seed(기본 123)로 학습된 모델에서 실시한다. 나머지 학습 seed는 학습 지표의 편차 확인에 사용한다.
- 샘플링 seed는 2026으로 고정한다. 모델이 예측한 확률에 비례해 다음 토큰을 추첨한다.
- `<eos>`로 종료한다. 최대 본문 길이 20토큰까지 허용한다. 형식 규칙을 생성 과정에 강제로 적용하지 않는다.
- 학습 문장 일치, 형식에 맞는 새 조합, 형식 오류·미완성의 세 범주로 분류한다. 합은 정확히 10,000개다.
- 형식은 주체 1개 + 대상 1개 + 행동 1개다. 가능한 조합 18개 중 기존 6개와 새 조합 12개를 구분한다.
- 원문과 다르지만 오류인 결과를 새 조합 성공으로 집계하지 않는다.
- 설정별 전체 생성 JSONL, 문장별 횟수·비율 CSV, 대표 예시와 선택 확률을 보관한다.

전체 흐름은 다음과 같다.

```text
문장 6개 → 같은 학습 쌍 24개
                  |
                  +-- 트라이그램
                  |     횟수 → 횟수 / 분모 → 다음 토큰 확률
                  |
                  +-- 신경망
                        임베딩 → 은닉층 → 출력층 → 확률 → loss
                           ↑        ↑        ↑             |
                           +--------+--------+-- 역전파 ----+
```

완전연결의 예시(`D = 2`, `H = 6`)에서 각 표시 하나는 학습 가능한 연결 가중치 하나다.

```text
        h1 h2 h3 h4 h5 h6
E1[0]   x  x  x  x  x  x
E1[1]   x  x  x  x  x  x
E2[0]   x  x  x  x  x  x
E2[1]   x  x  x  x  x  x

E1 = 철수는의 임베딩, E2 = 사과를의 임베딩
x = 각 입력 성분과 은닉 뉴런 사이의 가중치

입력 성분 4개 × 은닉 뉴런 6개 = 가중치 24개
일반식: (2 × D) × H, 은닉층 편향 H개는 별도
```

## 7. 진행 순서

1. 데이터·토큰 ID·24개 학습 쌍을 손으로 계산한 예시와 대조한다.
2. 트라이그램 카운트와 조건부 확률을 구현하고 확인한다.
3. 한 학습 쌍의 순전파와 각 단계의 값·배열 크기를 확인한다.
4. 역전파를 구현하고 모든 학습 가능한 변수의 gradient를 검증한다.
5. 학습을 연결하고 임베딩 1·2·3차원을 같은 조건에서 비교한다.
6. 미관측 문맥의 예측 분포와 임베딩 변화를 함께 해석한다.

각 단계의 작은 계산 예시와 실제 결과를 세션에서 설명한다.

## 8. 구현 시 검증 기준

- 데이터: 문장 6개, 일반 어휘 8개, 특수 토큰 포함 11개, 학습 쌍 24개.
- 트라이그램: 손으로 센 횟수·분모와 일치하고, 정의된 각 분포의 합이 1.
- 신경망: `D = 1, 2, 3` 및 서로 다른 `H`에서 배열 크기와 완전연결 수가 일치.
- 확률과 loss: 확률 합이 1이고, 큰 logits에서도 계산이 안정적.
- 역전파: 작은 고정 데이터에서 중심 차분 수치 미분과 직접 구한 gradient를 비교. 반복된 단어 ID의 임베딩 gradient 누적도 포함.
- 학습: 재현 가능한 초기화와 보수적인 학습률에서 loss 감소와 임베딩 갱신을 확인.

## 9. 확정된 선택과 변경 가능한 값

확정된 요구사항은 문장 6개, 단어 단위 트라이그램, Node.js, 직접 구현하는 순전파·역전파, `D = 1, 2, 3`, 변경 가능한 `H`, 임베딩 입력과 은닉층의 완전연결이다.

1. **언어**: TypeScript. Python·C는 후속 선택이다.
2. **미관측 문맥 처리**: MLE와 add-k를 함께 제공한다.
3. **결과**: 세션 시각화, JSON·CSV·Markdown·HTML 리포트, 전체 생성 JSONL.
4. **설정**: D, H, 학습률, 반복 횟수, seed, k, 생성 개수, 최대 길이는 명령행에서 변경할 수 있다. H=6으로 고정하지 않는다.

시각화에 사용하던 D3를 제거했다. SVG 생성·좌표 변환·눈금·경로는 `svg.js`, 차트는 `training-charts.js`, 재생 상태는 `training-animation.js`에서 직접 구현한다. TypeScript·Node 타입 정의는 사용자 합의에 따라 개발용으로 유지한다. 전체 흐름과 소스 발췌는 `npm run explain`으로 `IMPLEMENTATION.md`와 단계별 HTML에 정리한다.

직접 구현한 임베딩·완전연결·softmax·cross-entropy·역전파와 수치 미분 검증은 이미 갖췄다. NumPy·C 대신 TypeScript를 선택했지만 프레임워크에 계산을 맡기지 않는 학습 목적은 동일하다. README에 순전파 6단계와 역전파의 수식 대응을 추가했다.

| ZIP 실험 | 현재 구현·기록 | 보완할 부분 |
| --- | --- | --- |
| 1. 트라이그램 10,000문장 | MLE·add-k 모두 생성, 횟수·비율 저장 | 핵심 완료 |
| 2. NPLM 10,000문장 | D·학습률 설정마다 생성, 새 조합·오류 분리 | 핵심 완료 |
| 3. 학습률 비교 | 4개 학습률 표·CSV, 대표 D2·H8·lr0.3·seed123의 loss·PPL 곡선 재생 | 여러 학습률의 곡선 비교, 목표 loss 도달 갱신 수, 경과 시간 |
| 4. 임베딩 차원 비교 | D=1·2·3, 학습 전후 좌표와 ASCII 위치 | 핵심 완료 |
| 5. 하이퍼파라미터 그리드 | D × 학습률 × seed; 실제 학습 H는 8 | H도 함께 바꾸는 그리드 |
| 6. 학습 중 임베딩 이동 | 대표 D2·H8·lr0.3·seed123의 20회 간격 전체 가중치 기록·이동 재생 | 다른 차원·학습률의 중간 이동 비교 |
| 7. 퍼플렉시티 비교 | 학습 24쌍의 평균 PPL | 원본 6문장 각각의 PPL, 새 문장 전체의 PPL |
| 8. 철수는+바나나를 검증 | 정확한 다음 토큰 분포, 전체 생성의 예시·빈도 | 이 문맥을 고정한 10,000회 다음 토큰 추첨, 단일 위치 PPL |
| 9. H=6 대 H=8 | H 설정 가능, 크기 검증·단일 쌍 trace 있음 | 같은 D·학습률·학습량에서 두 H의 실제 학습 비교 |

핵심 구현 요구와 ZIP의 모든 실험 재현을 구분한다. 새로 실행하지 않은 비교는 결과로 보고하지 않는다.

### 다음 보완 순서

1. **여러 학습률의 곡선 비교**: 대표 설정의 곡선·가중치 재생은 `npm run animate`로 구현했다. 기존 `loss.csv`를 이용해 여러 학습률을 함께 비교하는 단계로 확장할 수 있다. 수렴 속도는 목표 기준을 명시하고 갱신 수로 비교한다. 실행 시간은 아직 기록되지 않았다.
2. **새 문장의 전체 확률과 문맥 고정 추첨**: 학습에 추가하지 않는 탐색용 문장을 정하고, 기존 어휘 ID를 그대로 써서 시작부터 `<eos>`까지 점수를 계산한다. `(철수는, 바나나를)`만 고정한 다음 토큰 추첨과 자유 문장 생성을 별도 실험으로 둔다.
3. **은닉층 비교**: 먼저 D=2, lr=0.3에서 H=6·8을 비교한다. 필요하면 H=4·16으로 넓힌다. 매개변수 수도 기록한다.
4. **다른 설정의 임베딩 이동**: 대표 D2 설정은 갱신 0~2,000회에서 20회 간격으로 기록·재생한다. 필요하면 다른 D·H·학습률을 같은 방식으로 비교한다.

### 선택적 확장과 명시할 차이

- 현재 옵티마이저는 **full-batch GD**다. SGD·mini-batch·Adam 비교는 후속 선택이다. 비교할 때 학습 쌍 노출 수와 갱신 수를 함께 기록하고, 어느 예산을 맞췄는지 밝힌다.
- Python·C 이식과 언어 간 수치 대조는 TypeScript 우선이라는 합의에 따라 후속 범위다.
- ZIP의 원시 n-gram은 미관측 문맥에서 균등 분포로 fallback한다. 현재 MLE는 미정으로 표시하고 add-k의 균등 분포와 구분한다. 이 정책 차이를 재현 결과의 차이와 혼동하지 않는다.
- 현재 생성 비율은 한 학습 seed의 모델과 한 샘플링 seed에서 얻었다. 여러 생성 seed의 비율 편차 확인은 후속 실험이다.
- `npm run animate`는 전체 가중치를 파일에 기록하고, 기록된 가중치를 복원해 확률과 생성 분포를 계산한다. 일반 명령행에서 임의의 파일을 불러와 추론하는 기능은 후속 범위다. `npm run trace`는 초기 모델의 계산 예시다.

### 협업과 작성 규칙

- 다음 계획에는 목적·바꿀 값·고정할 값·확인할 지표·저장 파일만 짧게 적는다. 결과를 본 뒤 다음 실험 하나를 고른다.
- 변수·함수는 영어 이름, 설명 주석은 한국어로 쓴다. 수학 변수와 배열 크기를 코드에 연결한다.
- AI가 작성한 구현의 정확성은 수치 미분, 확률 합, 실제 학습 감소, 생성 집계로 확인한다. 현재의 검증 결과와 새 실험에서 아직 확인하지 않은 결과를 구분한다.
