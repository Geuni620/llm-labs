# 챕터 2 — 한국어 N-그램 언어 모델

Chatbot_data의 일상 답변을 사용해 글자 묶음, 빈도, 확률을 확인합니다. 대화에서 작은 예시를 이해하고, 같은 계산을 전체 데이터에서 조회하는 방식으로 학습합니다.

이번 세션의 질문과 실험 결과는 [학습 회고](docs/learning-journey.md)에 정리했습니다. 전체 흐름과 다음 실습 목록은 [세션 기록](SESSION_REVIEW.md)에서 확인합니다.

## 학습 순서와 파일

1. `data/`, `prepare_data.py`: 원본과 정제된 답변을 비교합니다.
2. [unigram](unigram/README.md): N=1, 글자 하나의 빈도를 셉니다.
3. [bigram](bigram/README.md): N=2, 앞 글자 하나별 다음 글자의 빈도를 셉니다.
4. [trigram](trigram/README.md): N=3, 앞 글자 두 개별 다음 글자의 빈도를 셉니다.
5. [ngram](ngram/README.md): N=4 이상으로 문맥을 늘려 비교합니다.
6. [글자 단위 문장 생성](generation/README.md): 최대 빈도 선택과 가중 추첨을 한 글자씩 따라갑니다. N=5, 7, 10의 문장 10개씩과 모든 선택 기록을 저장했습니다. 이후 확장은 [추가 계획](generation/PLAN.md)에 정리했습니다.

## N-그램 빈도표 만들기와 조회

프로젝트 루트에서 실행합니다.

```sh
python3 part1/chapter2/count_ngrams.py
python3 part1/chapter2/count_ngrams.py --n 2 --context 하 --top 10
python3 part1/chapter2/count_ngrams.py --n 3 --context 하세 --top 10
```

각 폴더의 `counts.csv`는 관측된 모든 N-그램을 저장합니다. 상위 10개 조회는 출력 개수만 제한합니다.

- `ngram`: 연속한 N개 글자
- `context`: 앞 N-1개 글자. N=1은 빈 문자열
- `next`: 마지막 글자
- `count`: 해당 묶음의 등장 횟수
- `context_total`: 같은 문맥을 가진 묶음들의 횟수 합
- `probability`, `percent`: `count / context_total`, 그 비율의 백분율

각 답변 안에서 한 글자씩 이동해 겹치는 묶음을 셉니다. 공백과 문장부호를 포함하며, CSV의 공백도 실제 데이터입니다. 콘솔에서는 공백을 `␣`로 표시합니다.

이 빈도표는 대화에서 계산한 값과 비교하도록 실제 글자 묶음만 셉니다. 시작·끝 토큰과 스무딩은 추가하지 않았습니다. 별도의 생성 스크립트는 각 N의 표에서 최대 빈도 또는 횟수 비례 추첨으로 후보를 선택합니다. 학습·평가 분할과 짧은 문맥 대체는 추가 학습 단계입니다.

## 학습용 데이터 정제

프로젝트 루트에서 다음 명령을 실행합니다. Python 표준 라이브러리만 사용합니다.

```sh
python3 part1/chapter2/prepare_data.py
```

- `data/daily_answers.txt`: 일상 대화 답변을 한 줄에 하나씩 저장한 학습용 문장 목록
- `data/cleaning_report.json`: 원본·결과의 해시, 정제 규칙, 실제 제거 건수, 중복 예시

레이블의 앞뒤 공백을 정리해서 `label=0`을 선택하고, 답변의 유니코드 표현을 NFC로 통일합니다. 보이지 않는 U+200B·U+FEFF 문자를 제거하고, 제어 문자와 공백을 정리한 뒤 빈 답변과 동일한 답변을 제외합니다. 숫자, 영문 약어, 문장부호, 감정 표현, 짧은 답변은 유지합니다.

현재 일상 대화 답변 5,290행에서는 중복 2,910행을 제외해 **2,380개의 문장**을 얻습니다. 빈 답변, URL, HTML 태그, 보이지 않는 문자, 제어 문자는 발견되지 않았으며, 텍스트 정규화로 문구가 바뀐 답변도 없습니다. 가장 많이 반복된 답변은 `맛있게 드세요.`로 22회 등장합니다.

각 질문에 같은 답변을 붙인 문답 데이터이므로, 답변만 학습하는 이번 실습에서는 동일한 답변을 한 번씩 사용합니다. 따라서 정제본의 빈도 통계는 중복 없는 답변 목록을 기준으로 계산됩니다. 학습용·평가용 데이터는 이 정제본을 기준으로 나눠야 같은 답변이 양쪽에 들어가는 것을 방지할 수 있습니다.

원본 CSV와 라이선스는 그대로 보관합니다. 생성된 답변 목록을 각 N의 빈도 집계에 공통으로 사용합니다.
