# 유니그램 — N=1

글자 하나가 묶음 하나입니다. `하루가`에서는 `하`, `루`, `가`를 각각 셉니다. 앞 글자 조건 없이 전체 글자 등장 횟수를 분모로 사용합니다.

프로젝트 루트에서 실행합니다.

```sh
python3 part1/chapter2/count_ngrams.py --n 1 --top 10
```

- `counts.csv`: 관측된 모든 글자의 횟수와 비율
- `summary.json`: 입력 데이터, 글자 수, 서로 다른 글자 수
- `context`는 빈 문자열이고, `next`는 글자 하나입니다.

공백과 문장부호도 한 글자로 셉니다. 단어 단위 유니그램은 다른 실습입니다.
