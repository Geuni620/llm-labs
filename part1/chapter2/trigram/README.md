# 트리그램 — N=3

연속한 글자 세 개를 묶습니다. `하루가요`에서는 `하루가`, `루가요`를 셉니다. 앞 글자 두 개를 문맥으로 사용해 다음 글자의 확률을 계산합니다.

프로젝트 루트에서 실행합니다.

```sh
python3 part1/chapter2/count_ngrams.py --n 3 --context 하세 --top 10
python3 part1/chapter2/count_ngrams.py --n 3 --context 하루 --top 10
```

- `counts.csv`: 관측된 모든 세 글자 묶음의 횟수와 조건부 확률
- `summary.json`: 입력 데이터와 전체 묶음 수, 서로 다른 문맥 수

`하세` 뒤의 후보를 조회할 때는 `하세`라는 두 글자 문맥이 분모의 기준입니다. 바이그램에서 `세` 뒤를 조회하는 경우와 사용하는 문맥이 다릅니다.

다음 단계: [일반 N-그램](../ngram/README.md)에서 N을 더 늘렸을 때 관측되는 조합과 문맥을 비교합니다.
