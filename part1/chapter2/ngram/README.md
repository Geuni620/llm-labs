# 일반 N-그램 — N을 바꾸는 실습

연속한 N개 글자를 묶고, 앞 N-1개 글자를 문맥으로 사용합니다. N=4이면 `하루가요`는 묶음 하나이고, 문맥은 `하루가`, 다음 글자는 `요`입니다.

프로젝트 루트에서 실행합니다.

```sh
python3 part1/chapter2/count_ngrams.py --n 4 --context 하세요 --top 10
python3 part1/chapter2/count_ngrams.py --n 5
```

N=4의 전체 빈도표와 설명은 `n4/counts.csv`, `n4/summary.json`에 저장됩니다. 다른 N을 실행하면 `n5`처럼 해당 N의 폴더에 결과가 생성됩니다.

N=1, 2, 3은 각각 `unigram`, `bigram`, `trigram`에 저장합니다. 모든 N은 같은 답변 데이터를 사용하며, 관측된 조합을 모두 저장합니다.

학습에서 확인할 점: 문맥을 길게 잡을수록 후보를 세밀하게 나눌 수 있지만, 관측되지 않는 문맥도 생깁니다. 빈도표가 빈 문맥을 찾아보고, 이후에 짧은 문맥으로 돌아가는 방법을 학습합니다.
